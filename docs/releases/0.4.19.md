The first release tested on a real car: a 2015 Hyundai Elantra, through a Vgate iCar Pro Wi-Fi, on a 30-minute drive.

## What's new

- **Monitor counters** on the Vehicle info screen and in the report. For each emission self-test, the car counts how many drives it finished out of the drives where it could run. Clearing codes doesn't reset these counters, so low numbers on a high-mileage car hint at a recent reset of the engine computer (worth knowing on a used car).

## Fixes

- **Faster live data.** On cars without the fuel-type value (PID 51), Obdaryn mistook the missing answer for an engine computer that can't answer several values at once, and asked for every value one at a time for the rest of the session. Live data now refreshes about three times faster on such cars.
- **Clearer module scan results.**
  - A module that answers "busy" is asked again instead of being given up on.
  - When a module refuses, Obdaryn explains the more telling reason. If the engine is running, it asks for a scan with the engine off and the ignition on. If the module only gives its codes in a diagnostic session, it says so: Obdaryn never opens one, to stay read-only, so those codes need the brand's own tool.
  - The engine computer shows as "Generic OBD-II only" instead of an error when it answers standard OBD-II but not the manufacturer requests. Its codes are on the Trouble codes screen.
  - No more "scan again with the ignition ON" for modules that are clearly powered.
- **VIN check digit.** European, Korean and Japanese VINs no longer show "Not valid": the check digit is mandatory only in North America and China, so it now reads "Not used".
- **Romanian layout.** Long labels that wrap to two lines no longer overlap the next row.
